# ROSMASTER 官方 Python 运动接口清单

核对日期：2026-10-19。对象：本机 Jetson 宿主机安装的 `Rosmaster_Lib 3.3.1`，不是所有镜像或后续版本的通用保证。本页列出全部 **38 个公开普通方法**，包括直接运动、停止、反馈、配置和辅助功能；另列构造/析构行为，排除 6 个私有实现方法。仅“库中存在”不等于当前固件支持、实物安装或设备测试通过。

## 1. 底盘直接运动：3 个方法

| 方法（省略 self） | 能做什么 | 参数、实现与限制 |
|---|---|---|
| `set_motor(speed_1, speed_2, speed_3, speed_4)` | 独立控制四路电机，正反转、不同输出组合 | 常规 PWM 值 -100～100，0 为零输出；内部裁剪到该范围，但特殊值 127 被原样保留，语义本次未确认，不用于实验。开环输出，不承诺轮速、转角或行驶距离；通道与实物轮位待核对 |
| `set_car_run(state, speed, adjust=False)` | 预定义前进、后退、左移、右移、左旋、右旋及停止 | 源码注释 state：0 停止、1 前进、2 后退、3 左移、4 右移、5 左旋、6 右旋；中文另列 7 停车，英文未列 7，当前固件含义未测。speed 注释 -100～100，是控制量，不是 m/s；实现未强制此范围。adjust 陀螺辅助在源码注明未开通，不能认定可用 |
| `set_car_motion(v_x, v_y, v_z)` | 整车纵向、横向、原地旋转，以及组合速度运动 | 官方麦轮定义：x 正向前/负向后（m/s），y 正向左/负向右（m/s），z 正向左旋/负向右旋（rad/s）。安装源码注释 X3PLUS：x/y ±0.7、z ±3.2；这些是库注释的输入范围，不是本机安全速度或性能实测。实现乘 1000 编码为 int16，并未按这些范围裁剪 |

前后＋横移可表达斜向平移；平移＋旋转可表达边移动边转向。底层分配与固件、车型、轮位有关，本机尚未验证整车速度接口。上述方法都不携带持续时间、目标距离、目标航向或地图坐标，应用必须另行安排反馈与停止。

网页整车课给出 x/y ±1.0、z ±5.0，与安装库的 X3PLUS 专用注释不同；不能把网页通用范围当作本机已验证范围。

## 2. 停止及运行状态：1 个额外方法

| 方法 | 作用与边界 |
|---|---|
| `reset_car_state()` | 源码注释为停车、关灯、关蜂鸣器；会发状态重置指令。本机未测试，不能当作已验收的机械臂急停 |

已有方法也可表达底盘停止请求：`set_motor(0,0,0,0)`、`set_car_motion(0,0,0)`、`set_car_run(0,0)`。这些是调用形式，不是三个新增方法；零 PWM、零速度和状态重置不应未经验证就混同为主动制动。当前类没有名为 `stop()`、`emergency_stop()` 的公开方法，也没有已确认的通信超时停车配置接口。析构/关闭串口不保证停车。

## 3. 机械臂、夹爪及 PWM 舵机：7 个方法

| 方法 | 作用 | 参数与边界 |
|---|---|---|
| `set_uart_servo(servo_id, pulse_value, run_time=500)` | 单个总线舵机原始位置控制 | 注释 ID 1～255，254 为广播；位置 96～4000；时间 ms，上限裁剪为 2000。实现对 ID 只检查小于 1，随后按字节截取，不靠它防止错误 ID。原始范围不是实物限位，广播不用于常规单关节测试 |
| `set_uart_servo_angle(s_id, s_angle, run_time=500)` | 单个总线舵机绝对角度控制，包含夹爪对应舵机 | 安装实现 ID 1～6；1～4/6 为 0～180°，5 为 0～270°，转换后调用原始位置接口。都是软件映射范围，不是实物安全范围；相对动作需先读当前位置再计算目标 |
| `set_uart_servo_angle_array(angle_s=[90,90,90,90,90,180], run_time=500)` | 一帧同时下发六个舵机目标 | 使用同一组角度范围，时间裁剪 0～2000 ms。不是碰撞规划或轨迹避障；默认数组不能当作本机已验证回零姿态 |
| `set_uart_servo_torque(enable)` | 向底板发送总线舵机扭矩开关 | 参数 >0 发送开启，其余发送关闭。关闭可能使机械臂失去支撑，不作为已验收急停；没有单关节参数 |
| `set_uart_servo_ctrl_enable(enable)` | 切换当前 Python 对象的舵机控制发送开关 | 只设置 `__arm_ctrl_enable`，不向底板发包，不中断已接收动作、不代表实际扭矩状态；主要阻止该对象的单/多舵机位置发送 |
| `set_pwm_servo(servo_id, angle)` | 控制一路 PWM 舵机输出 | ID 1～4，角度裁剪 0～180°；与六轴总线舵机接口不同，实物是否接入待核对 |
| `set_pwm_servo_all(angle_s1, angle_s2, angle_s3, angle_s4)` | 一次设置四路 PWM 舵机 | 合法角度 0～180°；非法值被编码为 255，其固件语义未核实，不能假定等同安全停止 |

没有独立名为 `open_gripper()`、`close_gripper()` 的方法；夹爪动作通过对应舵机角度表达，开合角度与机械范围需以本机验证为准。

## 4. 运动与状态反馈：10 个方法

| 方法 | 返回或用途 | 实现注意 |
|---|---|---|
| `get_motor_encoder()` | 四路编码器计数元组 | 读接收线程缓存，没有采样时间；轮径、减速比、每圈计数与轮序未标定，不能直接当距离 |
| `get_motion_data()` | `(v_x,v_y,v_z)` | 读底板上报缓存；本次未验证速度精度或里程计 |
| `get_imu_attitude_data(ToAngle=True)` | `(roll,pitch,yaw)` | 默认度，False 为弧度；实际返回顺序与上方注释“yaw,roll,pitch”不同，按实现顺序读取 |
| `get_accelerometer_data()` | 三轴加速度数据 | 缓存反馈，坐标/标定另验 |
| `get_gyroscope_data()` | 三轴角速度数据 | 缓存反馈，坐标/标定另验 |
| `get_magnetometer_data()` | 三轴磁力计数据 | 缓存反馈，不保证环境下航向有效 |
| `get_battery_voltage()` | 电池电压，V | 缓存值除以 10；未校准，不能单独据此判断带载供电 |
| `get_uart_servo_value(servo_id)` | `(返回ID, 原始位置)` | 主动请求后等待接收线程；超时 `(-1,-1)`、异常 `(-2,-2)`，需核对返回 ID |
| `get_uart_servo_angle(s_id)` | 单舵机软件映射角度 | 调用原始位置查询；超时/越界等返回负值，不能当有效角度 |
| `get_uart_servo_angle_array()` | 六舵机软件映射角度列表 | 主动整体查询；失败项 -1、异常返回全 -2；实现不等同逐关节实物限位检查 |

缓存 getter 不等于每调用一次就重新采样；未启动接收线程、无上报或数据已过期时，可能读到初始零值或旧值。需另做新鲜度/超时管理，不能用旧零值宣布已停止。

## 5. 通信、车型和速度环配置：8 个方法

| 方法 | 作用与影响 |
|---|---|
| `create_receive_threading()` | 启动串口后台接收/解析线程；原厂 getter 的缓存更新和查询应答依赖它，不提供运动控制线程 |
| `set_auto_report_state(enable, forever=False)` | 开关底板自动上报；forever=True 设置持久标志。关闭会影响反馈，不是停车 |
| `clear_auto_report_data()` | 只清当前对象部分缓存：速度、电压、IMU 等；不发底板指令、不清编码器缓存、不停车、不重置硬件里程 |
| `set_pid_param(kp, ki, kd, forever=False)` | 设置整车速度控制相关 PID；范围各 0～10，True 写持久配置。默认无需为了使用接口而调整 |
| `get_motion_pid()` | 主动请求 PID，返回 `[kp,ki,kd]`；超时 `[-1,-1,-1]` |
| `set_car_type(car_type)` | 修改当前对象车型并发送带持久标志 `0x5F` 的底板配置；X3=1、X3PLUS=2、X1=4、R2=5 为库常量。不是单纯修改环境变量，不能为绕过启动限制随意调用 |
| `get_car_type_from_machine()` | 查询底板车型；超时 -1，不能代替实物型号识别 |
| `get_version()` | 请求/缓存底板版本，格式高字节＋低字节/10；失败 -1；不是 Python 驱动库版本 |

## 6. ID、校准及恢复：3 个方法

| 方法 | 作用与影响 |
|---|---|
| `set_uart_servo_id(servo_id)` | 改总线舵机 ID，范围 1～250；源码要求只连接一个，否则可能把多个改成同一 ID。不是运动命令，不用于日常测试 |
| `set_uart_servo_offset(servo_id)` | 设置中位偏差；注释 ID 0～6，0 恢复全部出厂偏差。会改变校准，返回状态需接收线程；源码没有与注释同等严格的范围检查，未验证持久化/恢复过程 |
| `reset_flash_value()` | 恢复底板 flash 默认配置；会影响已有配置，不能当作无损停车或排障快捷操作 |

## 7. 阿克曼车型专用：3 个方法

库为多车型共用，这些方法存在不表示 X3 Plus 有对应转向机构。

| 方法 | 作用与范围 |
|---|---|
| `set_akm_default_angle(angle, forever=False)` | R2 前轮转向舵机默认角度 60～120°；True 持久保存 |
| `set_akm_steering_angle(angle, ctrl_car=False)` | 相对默认角度的转向 -45～45°；注释左负右正；True 同时要求修改左右电机速度。不是本机麦轮横移接口 |
| `get_akm_default_angle()` | 请求/缓存阿克曼转向默认角度，超时 -1 |

## 8. 非运动辅助：3 个方法

为保证公开方法清单完整，一并列出；不属于底盘或机械臂运动。

| 方法 | 用途 |
|---|---|

## 初始化、错误与本机验证范围

- `Rosmaster(car_type=1, com='/dev/myserial', delay=.002, debug=False)`：默认车型是 X3 的 1，不是 Plus 的 2；构造时打开 115200 串口，且**自动调用 `set_uart_servo_torque(1)`**。只想读反馈也不能把实例化当作纯只读操作。传入 car_type 与调用持久化 `set_car_type` 是不同操作。
- `__del__()`：关闭串口并修改对象内部状态，**没有发送底盘停止或机械臂急停**。
- 6 个私有实现：`__parse_data`、`__receive_data`、`__request_data`、`__arm_convert_value`、`__arm_convert_angle`、`__limit_motor_value`；另有构造/析构，共 46 个有效方法定义。`set_yaw_pid_param`、`get_yaw_pid` 仅存在于注释中，当前不可调用。
- 很多 setter 捕获异常后只打印消息，正常调用也通常返回 None。None、无异常或串口写出均不是执行成功回执；应用仍需检查参数、当前反馈和实物动作。
- 当前用户整车示例两次读回固件 3.5、底板车型 1；线程修复版该次退出正常，但动作被拒绝。新增显式 `--configure-x3plus` 使用官方持久化设置后单独读回，尚无实物执行结果；源码接口、上层脚本与设备配置分别说明，见[操作入口](../guides/chassis.md)、[用户证据](../reports/2026-10-19-motion-demo-preflight.md)。
- 本项目已用独立脚本直接发送对应协议，取得单舵机有限往返、底盘 1 路 PWM 和编码器反馈证据；这不等于逐个调用并验收了本页全部原厂 Python 方法。整车速度接口、2～4 路独立驱动、同步整臂、实际限位、断线停车与急停仍待验证。地面测试其他编码器变化的解释见[更正后的报告](../reports/2026-10-19-motor-test.md)。
- 类中没有直接提供“前进指定米数”“转到指定航向”“到地图坐标”“避障”“末端移动到 xyz”方法。这些需要里程计/定位、任务逻辑、导航或机械臂运动规划；不能从速度/角度接口直接推出这些能力已可用。
