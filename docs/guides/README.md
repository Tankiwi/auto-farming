# 小车基本文档与使用说明

版本：v2｜更新：2026-10-20｜最新证据：用户传感器日志与随后只读复查；本次整理未连接设备。旧版长文已按任务拆分，步骤、历史参考值和限制保存在下列专题。

## 操作路径

1. 阅读[状态](../status.md)，确认需要的能力是否验收，以及记录日期。
2. 查[硬件与接线](../environment/hardware.md)和[远程连接](remote-access.md)，使用前复核地址与设备映射。
3. 传感器任务按[传感器指南](sensors.md)上传三个脚本，以 astra/microdia/lidar/imu/all 选择启动；另一个加载 Humble 环境的终端运行订阅程序。IMU 与底盘/机械臂共享串口，禁止重复占用；当前数据与启动验证范围见[日志报告](../reports/2026-10-20-sensors-startup.md)。
4. 机械臂课程仿真见[复现步骤](arm.md#课程仿真复现)与第 1～8 课历史验收；按[Noetic 教程指南](arm.md)进入独立容器，按该指南保存配置和停止。master、图形窗口、模型加载、仿真规划、真机控制分别验收。
5. [数据录制与回放](data-recording.md)仍为待验证模板；先复核磁盘和输出目录。
6. 查自启动、驱动安装和底板基础功能时，读[厂商基础控制资料](../references/basic-control-courses.md)；这是待适配的参考，先核对版本、串口占用、回退与停止条件。
7. 底盘电机与整车示例见[分步指南](chassis.md)：区分悬空单轮脚本和地面速度示例，按上传、显式配置、运动三步处理。当前用户日志仍读回底板车型 1，运动被拒绝；新增配置选项无设备执行结果。恢复完整底盘开发仍需补[固件资料](../modules/chassis.md)。出错时看[故障排查](../troubleshooting/README.md)。

这些流程用于已有记录的环境。启动成功不等于当前设备、底盘协议或停止行为已确认。固件、部署版本及整车导航缺口统一维护在[待验证清单](../pending.md)。

## 结束与交接

传感器在各启动终端按 `Ctrl+C` 后检查节点；机械臂按专题关闭助手、停止 master 和容器。关闭 SSH 窗口不能代替停止检查。真机停车与急停方法尚未验收，不能从上述软件停止步骤推断实物已安全停止。

新增事实写入对应专题并追加[变更记录](../changes/README.md)；原始数据留日期、条件、来源及归档位置。参考资料见[资料索引](../references/README.md)。本次整理只更新本地文档，没有连接设备或部署脚本；此前设备操作以带日期报告为准。
